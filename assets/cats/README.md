# 猫猫设计资产

保留供后续界面复用的猫图标与视觉参考，文件保持原样：

- `icon.svg`、`icon.png`：来自原 `apps/shell/src-tauri/icons/` 的猫图标。
- `references/`：来自本地 `reference/` 的 7 张原始 WebP 设计参考图，包含猫形角色、装饰与界面布局。

当前墨水屏界面没有引用这些素材。参考图的作者及授权来源尚未记录；根目录 MIT 许可证不构成对这些第三方参考图的授权声明。它们未打包进 APK，复用或再分发前请自行核实权利来源。

[SHA256SUMS](SHA256SUMS) 记录全部 9 个素材的校验值，迁移前后逐文件一致。在此目录运行 `sha256sum -c SHA256SUMS` 可验证。
