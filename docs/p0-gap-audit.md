## 实现形态误称检查

当前 UI 不是 React/TypeScript 完整 UI：`apps/ui/app.js` 是原生 JavaScript，页面是单个静态 `index.html`，只有四个导航占位面板、硬编码额度/节点/会话数据和一个演示审批 `<dialog>`；没有 React 依赖、组件树、领域状态或 App Server 适配器。Tauri Rust 仅暴露 `p0_environment`。因此只能称“统一静态 P0 骨架/交互探针”，不能称完整工作台或已实现 React 前端。

## 检查可重复性

主 agent 已在仓库固定的 Nix 开发环境执行 `cargo test --workspace`：App Server 适配器 6 项、运行时 5 项、领域层 23 项、协议层 4 项测试均通过；工作区 clippy 严格模式通过。另显式执行被忽略的 Tauri 壳真实 App Server 测试并通过。该证据不替代局域网或窗口级 UI 端到端测试。
