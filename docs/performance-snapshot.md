## 采集条件

- Poke3 屏幕点亮，`dev.nekodex.workbench/.MainActivity` 为前台 resumed activity。
- Android 与 Linux 均为此前部署的同版只读监控构建，没有为本次采集重启或重建。

- CPU 只做 10 秒有界空闲采样；没有操作页面、触发刷新或执行长时间压测。

## 边界

这份报告只证明当前设备、当前页面与当前连接状态下的一次基线，不证明：

- 长时间待机平均值、耗电或温升；
- 页面连续滚动、中文长文本和大列表时的峰值；
- Android 系统回收、后台恢复或旋转后的资源释放；
- 多于两个节点和多个同时在线来源时的资源上界。

后续验收应在实现或运行条件发生变化时补充对应场景，不重复用同一空闲快照替代其他性能要求。
