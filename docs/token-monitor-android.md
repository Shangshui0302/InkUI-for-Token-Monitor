# Token Monitor 独立 Android APK

Android 工程在 `apps/android/`，直接把 `apps/eink/` 的正式页面编入安装包。界面与局域网浏览器版共用同一份源码，包含黑白模式、六种亮色重点色、五页看板、按钮分页和字段详情。无需电脑提供静态网页即可打开应用；在线数据由用户选择的局域网服务提供。

## 连接与数据范围

首次打开进入连接编辑页，通过“上页／下页”依次填写地址、密钥并选择“保存并连接”。设置中的“编辑”可修改连接，“连接”可分页查看读取结果与完整来源地址。

| 来源 | 地址示例 | 凭据 | 提供的数据 |
| --- | --- | --- | --- |
| Hub | `http://192.168.1.10:17321` | Token Monitor Hub 密钥 | 日／月／累计统计、费用、额度、模型／工具／项目／设备、Hub 已暴露的会话、活动历史 |
| 归档（可选） | `http://192.168.1.10:18788` | 墨水屏只读网关的查看令牌 | 电脑端已经留存的累计会话及字段详情 |

地址只填写 `http(s)://主机:端口`，不包含接口路径、用户名、查询参数或令牌。密钥输入留空保留当前同一来源的密钥，“清除”在保存时删除它；更换来源地址时不会把原密钥自动带到新主机。归档与 Hub 使用独立密钥。

当前 Hub 没有 `/api/session-archive`；需要完整保留浏览器版的本机累计会话时，在电脑继续运行现有只读网关，启用 `--session-archive`，再把该网关地址填入 APK 的“归档”。网关启动见 [浏览器版说明](../README.md#启动)。未配置归档时仍展示 Hub 已提供的信息，并在数据来源中说明归档不可用，不把缺失内容当成零。

会话归档只涵盖该电脑已有的用量留存，不代表跨设备完整对话历史。额度是上游采集快照；刷新 APK 只会重新读取 Hub，不直接请求服务商。当前版本不包含服务商登录或直查。

## 本地与网络行为

- 本地页面使用固定虚拟 HTTPS 来源，由 Android 读取包内资源；外部页面、文件访问、弹窗和页面导航被阻止。原生层只转发三个固定 GET 接口，不转发任意 URL、Cookie 或页面提供的请求头。
- Hub／归档凭据使用 Android Keystore 的 AES-GCM 密钥加密，整条配置原子写入应用的 `noBackupFilesDir`；备份关闭。页面只能取得地址、是否保存密钥及配置版本，不能读取已保存密钥。
- 网络层不跟随重定向、不使用系统代理，保留标准 HTTPS 证书验证。连接与读取各有 8 秒超时，响应限制 8 MiB。HTTP 局域网连接的传输本身没有加密，可使用系统信任证书的 HTTPS 地址。
- 直连 Hub 时配置的是 Hub 原有密钥；上游该密钥也可授权写接口。APK 只实现 GET，不能将其解释为上游已提供独立只读权限。需要限制客户端权限时，可以把现有只读网关同时作为 Hub 和归档来源。
- 统计、历史、归档分别保存最近成功的展示缓存；切换来源会清除三类数据缓存并丢弃旧请求结果，保留配色和刷新偏好。断线时明确显示缓存状态。
- 默认 60 秒刷新，支持 5 分钟或手动。应用退到后台暂停读取并断开进行中的原生请求，回前台恢复；没有常驻服务或唤醒锁。Android 返回键先退出输入／字段详情／设置，再回桌面。

## 构建和签名

需要已有 JDK 17 或更新版、Android SDK platform 36 及匹配 build-tools。构建入口只运行独立 Android 工程，不涉及旧 Tauri、Rust 或桌面构建。Gradle wrapper 固定为 8.14.3，Android Gradle Plugin 为 8.11.0。首次依赖解析需要网络或已有 Gradle 缓存。

```bash
export JAVA_HOME=/absolute/path/to/jdk
export ANDROID_HOME=/absolute/path/to/android-sdk
tools/build-eink-apk.sh debug
```

输出为 `output/android/token-monitor-eink-debug.apk`，包名 `dev.tokenmonitor.eink.debug`。Debug 版允许 WebView 调试，供真机验收使用。

正式安装包需要持久保存的私有签名密钥和 properties 文件，字段模板见 `apps/android/keystore.properties.example`。真实密钥和密码不放入仓库：

```bash
export TOKEN_MONITOR_SIGNING_FILE=/absolute/private/path/release.properties
tools/build-eink-apk.sh release
```

输出为 `output/android/token-monitor-eink-release.apk` 及 SHA-256 文件，包名 `dev.tokenmonitor.eink`。Release 关闭应用调试和 WebView 调试，缺少签名配置时构建失败。后续更新必须保留相同包名及签名，并增加 `versionCode`；APK 不包含个人 Hub 地址或凭据。

最低 Android 10（API 29），当前目标是 Poke3；没有原生 CPU 架构库。系统 WebView 必须支持现有页面使用的 JavaScript 模块及相关浏览器 API。

## 2026-10-25 验收

- Debug、Release APK 均已生成，Release 的签名验证及 Android 29 最低版本检查通过；包内 11 个前端资源与当前共用源码逐字节一致，不包含个人地址、凭据或测试数据。Release 不可调试，WebView 调试关闭。
- Poke3 Android 10、系统 WebView 108 实机安装运行通过，真实 CSS 视口约 662×453。正式包已配置局域网只读网关，统计、完整历史及本机会话归档均可读取；验收时包含三家服务商、23 个历史日期和 949 条归档会话。数据数量会继续变化。
- 当前电脑的防火墙配置允许 18788，未列入 17321；真机直连 17321 超时，18788 可达。因此当前 Hub／归档两项均连接既有 18788 只读网关。APK 直接读取 Hub 的 stats／history 已另通过临时 USB reverse 验证，不能将这项记为 17321 的 Wi-Fi 直连验收。放行 Hub 端口后可以修改地址及密钥，无需重新打包。
- 新连接／状态页在 11 种模拟尺寸（128×128 至 1920×1080）检查 99 个状态，无滚动或内容溢出。真机软键盘把视口压缩到约 662×225 后，输入及翻页仍可见，根滚动偏移为零。模拟尺寸不等于其他实体设备验收。
- 真机验证了字段详情的 Android 返回键、退后台拒绝读取和回前台恢复。正式版另验证新进程冷启动恢复加密连接、网关中断时明确保留缓存、网关恢复后重新联网。
- 原生固定路由拒绝写请求、未知接口及查询参数；受控重定向测试未向目标发出请求；切换来源后旧响应返回 `connection_changed`，不会写回新缓存。查看密钥未进入网页存储，原生配置文件只含加密封装。
- 13 项 HTTP 测试、5 项连接逻辑测试、原生 policy 检查及语法检查通过；Chrome 85 浏览器模式的认证、刷新及 12 条总览回归通过。既有数据模型和配色检查沿用同一份未改变源码的有效结果。新增检查与截图在被忽略的 `output/playwright/apk-*`，构建日志在 `output/android/`。
- Poke3 开启了第三方应用冻结，安装后系统曾自动禁用新包；验收时已启用正式包。若设备以后将其冻结，可在设备应用管理中解除冻结，不需要清除应用数据。未改动全局冻结设置。

长期耗电、长期残影及其他品牌实体彩屏尚未测试。电脑端 Hub 和可选归档网关仍需运行；本次没有配置它们的系统自启动，也没有修改 NixOS／Home Manager 或执行系统 rebuild。
